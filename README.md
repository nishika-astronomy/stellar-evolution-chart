# Stellar-Evolution-Chart
An interactive astronomy project that visualizes the complete life cycle of stars. Explore animated stellar evolution pathways, stellar remnants, branching mass-
dependent outcomes, and detailed encyclopedia-style popups with scientifically accurate astrophysical information.

https://nishika-astronomy.github.io/stellar-evolution-chart/

🌌 Scientific Framework

The chart is rooted in the standard model of stellar evolution, which describes a star's life as a continuous struggle to maintain hydrostatic equilibrium—the balance between the inward pull of gravity and the outward pressure generated by thermonuclear fusion.

Core Evolutionary Stages

Protostars: Formed by the gravitational collapse of giant molecular clouds driven by Jeans instability.

Main Sequence: The longest phase of a star's life, characterized by core hydrogen burning. The star's position on the Hertzsprung-Russell diagram is dictated strictly by its initial mass.

Post-Main Sequence: As core hydrogen is exhausted, stars deviate from the main sequence, expanding into Red Giants or Supergiants depending on their mass, driven by shell burning.

End States (Stellar Remnants): * White Dwarfs: The remnant of low-to-intermediate-mass stars, supported by electron degeneracy pressure.

Neutron Stars: The dense remnants of massive star supernovae, supported by neutron degeneracy pressure.

Black Holes: The final state for the most massive stars, where the mass exceeds the Tolman-Oppenheimer-Volkoff (TOV) limit, resulting in gravitational collapse beyond a point of no return (the event horizon).

🛠️ Technical Overview

The application utilizes an immersive, hardware-accelerated approach to data visualization:

View Layer: * SVG (Scalable Vector Graphics): Used for the interactive nodes and evolutionary path links, allowing for crisp scaling and DOM-based event handling.

Canvas API: Used for a performant, high-density background particle system that simulates cosmic dust and nebular environments.

Interactions:

Viewport Management: Custom pan/zoom logic using pointer and touch event listeners, supporting mobile and desktop inputs.

Information Density: An integrated HUD (Heads-Up Display) system that triggers glassmorphic modal windows, providing detailed astrophysical data for each stellar stage.

Dependencies:

Tailwind CSS: Used for responsive UI components.

Lucide Icons: Provides lightweight, semantic vector icons for the user interface.

🚀 Usage Guide

Exploration: Click on any stellar node to open an "Encyclopedia Card." These cards detail the physical properties (temperature, luminosity, radius) and nuclear mechanisms active during that specific evolutionary stage.

Navigation:

Mouse: Click and drag to pan; use the mouse wheel to zoom.

Touch: Single-finger drag for panning; pinch-to-zoom for scale adjustment.

Performance: The background simulation is optimized using requestAnimationFrame. If performance dips on older hardware, minimize browser windows to reduce paint calls.
